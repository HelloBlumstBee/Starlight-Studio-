# Starlight Studio — Planned Licensing Model

> **Information only.** The software EULA and SDK licenses have not been finalized. This document is not a grant of permission to copy or redistribute proprietary software.

| Part | Planned approach |
| --- | --- |
| Starlight Studio Core | Proprietary, closed source |
| SDK interfaces and selected examples | Public, with specific terms/licensing to be announced |
| Independently developed plugins | Remain the respective authors' property, subject to SDK terms |
| Original vehicle mods made by users | Remain the creators' property, subject to third-party rights |
| Modified redistribution of the application | Requires express authorization; must be marked unofficial and credit the original project |
| Website assets and branding | Not a blanket open-source license; do not imply official affiliation |

The plan is to offer a **proprietary core with extensibility through a community SDK**. It should not be described as a fully open-source application.

Starlight Studio is being developed with Qt 6. Licensing obligations for particular Qt modules and other third-party dependencies will be reviewed before distribution.

Starlight Studio is independent from BeamNG GmbH and is not its official software.
