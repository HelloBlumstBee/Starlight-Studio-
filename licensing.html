Licensing Approach

Planning document — not a software license. No final EULA or SDK license has been issued. Please do not interpret this public website as a grant of rights to Starlight Studio's proprietary core.

A protected application core with room for independent extensions and original creative work.

Starlight Studio Core

The desktop application's core code and protected assets are planned to remain proprietary and closed-source. Publishing this information website does not license the underlying application source for copying, modification or redistribution.

Public SDK

Selected SDK interfaces, headers, documentation and example plugins may be published separately. Specific licenses and conditions will be provided alongside those components at launch. The SDK is not yet available.

Community-created plugins

Independent developers will be able to create extensions under the future SDK terms. A community plugin is not the same as a redistribution of the main application. Identifying compatibility is welcome when accurate and not misleading.

Modified application distributions

Redistributing proprietary Starlight application binaries or altered versions containing core components requires separate authorization. Where distribution is expressly approved, versions must clearly credit Starlight Studio and disclose that they are independently modified, not official.

User-created work

Creators retain their rights in original vehicle mods, models and projects. Starlight Studio does not claim ownership just because the software helped create them. Third-party rights still apply.

Third-party dependencies

Starlight Studio is built using C++20 and Qt 6. The final distribution will need to comply with applicable Qt and other dependency licenses. BeamNG.drive is a product of BeamNG GmbH; Starlight Studio is an independent, unaffiliated project.

Read the Community Policy for the planned extension guidelines. Final licensing terms will be reviewed before a public software release.
