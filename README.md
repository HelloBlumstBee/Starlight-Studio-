# ✦ Starlight Studio

**Your Creation. Your Rules.**

An upcoming C++20 / Qt 6 desktop workspace designed to make creating, inspecting, and editing vehicle mods for **BeamNG.drive** more approachable.

**Status:** Coming soon · In active development · No public application download yet.

## What we're building

- **3D + JBeam** — visually inspect vehicle meshes, nodes and beams.
- **Vehicle creation** — prototype frame and chassis generation.
- **Star Engine Labs** — early engine configuration tools.
- **Creator workflow** — bring geometry, physics, files, components and diagnostics closer together.
- **Community SDK** — planned extension interfaces for developers.

The editor and its visualization tools are in prototype development. **Operation FIRST LIGHT** aims to generate and export a first complete experimental vehicle, **STAR-01 BRICK**, and test it in BeamNG.drive. This milestone has not yet been verified in-game.

## Licensing philosophy

- **Core application:** Proprietary and closed-source.
- **SDK:** Selected components planned to be publicly available under licenses to be determined.
- **Community extensions:** Supported via future official interfaces.
- **User-created mods:** Original work remains its creators' property, subject to third-party rights.
- **Modified application distributions:** Need specific authorization and clear attribution; not automatically allowed.

This repository intentionally **does not provide an open-source license** to Starlight Studio's proprietary application. Future EULA and SDK terms will be published separately.
